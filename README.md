# AMBER Streetwear

AMBER es una web premium de streetwear con estilo rebelde, moderna y responsive.  
Está preparada para GitHub Pages y para empaquetarse como app móvil con Capacitor.

## Incluye

- Web responsive para móvil, tablet, PC y Mac.
- PWA con manifest y service worker.
- Estructura lista para iOS y Android con Capacitor.
- Logo original incluido en `assets/brand/`.
